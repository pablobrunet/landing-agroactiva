# Landing Agroactiva

Landing de recursos para Agroactiva 2026, con biblioteca de prompts por vertical agropecuaria, método MAPA y rutas internas de detalle.

## Scripts

- `npm run dev`: entorno de desarrollo.
- `npm run build`: build de producción.
- `npm run start`: servir build de producción.

## Stack

- Next.js
- React
- Tailwind CSS
- MDX
